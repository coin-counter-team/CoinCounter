# 데이터

원본 사진은 용량과 개인정보 문제로 저장소에 올리지 않고 팀 공유 드라이브에 보관합니다. 로컬에서는 `data/raw/`에 두면 `.gitignore`로 제외됩니다. 정답 CSV만 `data/labels/`에 올립니다.

## 촬영 가이드

| 항목 | 기본 조건 | 확장 조건 |
| --- | --- | --- |
| 배경 | 단색 (고정) | 밝은 단색 / 어두운 단색 |
| 조명 | 기본 | 기본 / 밝음 / 어두움 |
| 거리·각도 | 고정 거리, 수직 촬영 | 동일 |
| 배치 | 동전끼리 겹치지 않음, 앞·뒷면·회전·혼합 | 동일 |
| 수량 | 100장 이상 (조정용 60 / 테스트 40) | 조건별 10장, 60장 이상 |

파일 이름: `<조건>_<묶음>_<번호>.jpg` (예: `base_g03_012.jpg`, `dark-bg_bright_g01_004.jpg`)

## 정답 CSV 형식

`data/labels/coins.csv` — 동전 한 개당 한 줄

| 열 | 설명 | 예시 |
| --- | --- | --- |
| `image` | 파일 이름 | `base_g03_012.jpg` |
| `split` | `tune` / `test` / `ext` | `test` |
| `group` | 연속 촬영 묶음 ID (split 간 중복 금지) | `g03` |
| `condition` | `base` 또는 `<배경>_<조명>` | `base` |
| `x`, `y`, `r` | 동전 중심 좌표와 반지름 (픽셀) | `412,280,57` |
| `value` | 금액 (10/50/100/500) | `100` |

이미지별 총금액은 `value`를 합산해 구합니다.
