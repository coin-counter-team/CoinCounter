# ORB 특징점 매칭 (이슈 #7, 담당: 정휘)

## 방법
1. `cv2.ORB_create`로 동전 crop과 기준(템플릿) 이미지의 특징점·디스크립터를 구한다.
2. `cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)`로 양쪽에서 서로 가장 가까운 쌍만 남긴다.
3. 해밍 거리가 `ORB_MAX_DISTANCE`(64) 이하인 매칭을 "좋은 매칭"으로 센다.
4. 점수 = 좋은 매칭 수 / 두 이미지 중 적은 특징점 수 (0~1). 특징점이 없으면 0.

`classify_by_orb(coin, templates)`는 `{금액: 템플릿 이미지}` 중 점수가 가장 높은 금액을 고른다.
ORB는 회전에 강하므로 동전이 돌아가 있어도 같은 무늬면 점수가 높게 나온다.

## 크기·색상 규칙과의 비교 계획
- 실제 사진에서 금액별 템플릿 crop을 1장 이상 준비한다 (현재는 합성 이미지 테스트만 있음).
- 정답 라벨이 있는 동전 crop 세트로 세 가지를 비교한다:
  (a) 크기·색상 규칙만, (b) ORB만, (c) 규칙 + ORB(규칙이 애매할 때 ORB로 결정).
- 지표: 금액별 정확도와 전체 정확도, 혼동 행렬(특히 10원/50원/100원 혼동), 처리 시간.
- 결과를 이 문서에 표로 추가한다.
