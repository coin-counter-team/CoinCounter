# Hybrid 실험 종료 결정

2026년 11월 28일 오현우 담당 검출 범위 정리.

Hough 후보 주변에서 Contour로 원을 다시 맞추는 Hybrid는 최종 프로그램에
반영하지 않고 추가 개발·병합을 진행하지 않는다. 제안서의 필수 범위인
Contour·Hough 구현과 두 방식 비교를 우선한다.

## 결정 근거

- Hough의 후보 수를 유지하므로 누락을 복구하지 않는다.
- 그림자를 실제 테두리로 선택해 크기 추정이 나빠지는 반례가 확인됐다.
- 개수 일치만으로 테두리 정확도 개선을 입증할 수 없다.
- 현재 근거만으로 기본 검출 방식으로 채택하기 어렵다.

## 브랜치 보관

feature/hybrid-detect의 마지막 확인 커밋은 0f31a5e159c6f6fa8399c03f6e66a2319df4166d다.
재현용으로 코드를 보관하되 진행 중 기능으로 취급하지 않는다.
이 정리에서는 원격 브랜치를 삭제·강제 변경하거나 Hybrid 병합 PR을 만들지 않는다.

브랜치에 이미지 읽기·비교 도구 수정도 섞여 있으므로, 필요한 수정은 최신 main과
대조해 따로 검토한다. 해당 수정을 가져오기 위해 브랜치 전체를 병합하지 않는다.
현재 main의 adaptive 전처리 안 Hough 마스크 복원은 별도 팀원 구현이며 유지한다.

최종 담당 범위와 결과는 [Contour와 Hough 비교](hough-contour-comparison.md)를 참고한다.
